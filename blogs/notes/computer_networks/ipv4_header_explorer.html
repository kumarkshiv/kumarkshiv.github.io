TTL: a packet's countdown

Each router subtracts 1 from TTL. If it reaches 0, the router throws the packet away and sends an ICMP "Time Exceeded" message back. This stops packets from looping forever. Because the header changes, every router must also recompute the header checksum.

This is how traceroute works: it sends packets with TTL 1, 2, 3 … so that each router in turn drops one and reveals itself with its "Time Exceeded" reply.

Fragmentation

A link can only carry packets up to its MTU. If a packet is bigger, a router splits it into fragments. All fragments share one Identification, every fragment except the last has MF = 1, and Fragment offset says where the data belongs, counted in 8-byte units.
